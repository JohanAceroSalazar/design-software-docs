## Terminos

| Termino | Definicion |
|---------|------------|
| Ambiente | Espacio fisico o logico donde se desarrolla la formacion. |
| Aprendiz | Estudiante vinculado a un proceso de formacion. |
| Instructor | Profesional que guia y evalua la formacion. |
| Ficha | Grupo academico asociado a un programa y periodo. |
| Horario | Distribucion planificada de sesiones en el tiempo. |
| Reserva | Bloqueo temporal de un ambiente o recurso. |
| SENA | Servicio Nacional de Aprendizaje. |
| Traceability | Capacidad de seguir cambios, decisiones y eventos relevantes. |
