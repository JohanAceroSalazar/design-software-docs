# Functional Requirements

> Estado: 🟡 | Ultima actualizacion: 2026-06-18
> Autor: Por definir | Equipo: Por definir

## Requisitos funcionales

- RF-01: El sistema debe permitir autenticar usuarios y controlar acceso por rol.
- RF-02: El sistema debe permitir administrar catalogos maestros.
- RF-03: El sistema debe permitir registrar y consultar programas, fichas y oferta academica.
- RF-04: El sistema debe permitir administrar ambientes, recursos y reservas.
- RF-05: El sistema debe permitir crear y validar horarios con deteccion de conflictos.
- RF-06: El sistema debe permitir administrar instructores, aprendices y actores externos.
- RF-07: El sistema debe permitir almacenar documentos y versiones.
- RF-08: El sistema debe permitir registrar auditoria y eventos de negocio.
- RF-09: El sistema debe permitir monitorear indicadores y alertas.

## Criterios generales

- Cada requisito debe tener una historia de usuario asociada.
- Los requisitos criticos deben tener pruebas de aceptacion.
