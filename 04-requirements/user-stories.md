## Historias de usuario

- US-01: Como coordinador, quiero consultar la disponibilidad de ambientes para planear horarios sin cruces.
- US-02: Como coordinador, quiero asignar instructores a sesiones para balancear cargas.
- US-03: Como instructor, quiero ver mi horario consolidado para organizar mi jornada.
- US-04: Como aprendiz, quiero consultar mis sesiones y cambios de horario.
- US-05: Como administrador, quiero mantener catalogos maestros sincronizados.
- US-06: Como auditor, quiero revisar el historial de cambios y aprobaciones.

## Criterios de aceptacion

- Cada historia debe tener flujo principal, excepciones y evidencia de prueba.
