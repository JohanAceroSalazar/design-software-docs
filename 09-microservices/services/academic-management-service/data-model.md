# Modelo de datos - academic-management-service

## Entidades principales

- `programs`
- `program_versions`
- `competencies`
- `groups`
- `group_members`
- `academic_offers`

## Reglas

- Un programa debe conservar version historica.
- Una ficha o grupo pertenece a un programa y periodo.
- Las relaciones academicas deben ser trazables por version.
