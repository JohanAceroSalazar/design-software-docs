# Servicios del proyecto SENA

Este directorio contiene la documentacion de cada servicio de microservicios del proyecto.

Cada servicio cuenta con:

- `README.md` - descripcion, responsabilidad, dependencias y enlaces.
- `api-contract.md` - endpoints, request/response y errores.
- `data-model.md` - entidades y relaciones principales.
- `events.md` - eventos publicados y consumidos.
- `runbook.md` - despliegue, configuracion y troubleshooting.
