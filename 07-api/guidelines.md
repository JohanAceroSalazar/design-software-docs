# API Guidelines

> Estado: 🟡 | Ultima actualizacion: 2026-06-18
> Autor: Por definir | Equipo: Por definir

## Lineamientos

- Usar versionado en la ruta.
- Nombrar recursos en plural y en forma consistente.
- Responder con errores estructurados.
- Validar entradas con esquemas o DTOs.
- Documentar codigos de error comunes.

## Convenciones

- `GET` para consulta.
- `POST` para creacion.
- `PUT` o `PATCH` para actualizacion segun el caso.
- `DELETE` para baja logica o fisica segun dominio.
